# НейроДети

Сайт семейных лабораторий нейросетей и AI-агентов.

Сайт: https://juliyanikitina.github.io/neurodeti/

## Направления

- Творческая лаборатория: изображения, персонажи, дизайн.
- Учебная лаборатория: создание собственных агентов-репетиторов и тьюторов.
- Кино и мультфильмы: сценарий, видео, звук и монтаж.
- Цифровая лаборатория: сайты, приложения и игры.
- Медиа и проявленность: блог, съёмка, монтаж и культура социальных сетей.
- Семейные исследования: источники, общие открытия и цифровые истории.

Это презентационная версия проекта обновлённой программы. Организационные данные, возрастные группы, часы, стоимость и документы требуют утверждения. Наличие образовательной лицензии не заявляется.

## Работа с сайтом

Статические файлы находятся в `docs/`. Установка зависимостей не требуется.

Локальный просмотр: `python -m http.server 4173 --directory docs`.

`main` — опубликованная версия. `codex/yulia` — отдельная ветка Юлии для дальнейших изменений. GitHub Pages публикует каталог `docs/` ветки `main`.

На сайте есть интерактивный пример составления инструкции учебному агенту; это конструктор промпта, а не подключённый чат с ИИ. 3D-помощник реализован на Three.js, поддерживает вращение мышью и клавиатурой. Уменьшение движения учитывает системную настройку пользователя.

Исходные фотографии детей и рабочие референсы в этот репозиторий не входят.
